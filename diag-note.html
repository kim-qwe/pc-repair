PC 꺼짐 진단 노트

2026-11-23 19:55 기준 · i7-8700K · ASUS PRIME B360M-K · RTX 3080 · 삼성 DDR4 16GB×2

원인: 메인보드의 램 A1 자리(메모리 채널 A) 쪽

같은 램(일련번호 끝 78B)이 B1 자리에서는 14판 동안 멀쩡했고, A1 자리에서는 8초 만에 꺼졌어요. 램, 파워, 그래픽 카드는 원인이 아니에요.

지금 할 일: 바이오스 전압 조금 올리기

램은 78B 하나만 A1에 꽂은 채로 해요. 그래야 전압만 바꾼 효과를 볼 수 있어요.

  1. 다시 시작하고, ASUS 글자가 보일 때 Delete를 여러 번 누르세요.
  2. F7을 눌러 고급 화면(Advanced Mode)으로 가세요.
  3. Ai Tweaker 탭에서 다음 두 항목을 바꾸세요. Manual을 먼저 고르라고 하면 Manual을 고른 뒤 숫자를 넣으세요.
항목지금 (Auto)바꿀 값
CPU System Agent Voltage (VCCSA)약 1.05V1.15
CPU VCCIO Voltage약 0.95V1.10
  1. F10 → OK로 저장하고 나가세요.
  2. Windows에 로그인한 뒤 Claude 세션에 "바꾸고 켰어"라고 알려 주세요. 같은 시험으로 고쳐졌는지 확인해요.

메뉴가 안 보이면 Ai Tweaker 화면 사진을 찍어 두세요. 이 보드(B360)는 전압 메뉴가 일부 빠져 있을 수 있어요.

거의 멀쩡. 당장 쓰려면 여기에 하나만.

원인이 아닌 것으로 확인된 것

  • 파워: 11-22에 새 1000W로 바꿨는데도 꺼졌어요.
  • 그래픽 카드: 꺼질 때마다 쉬는 중(17W)이었어요. 연결이 x4일 때도 B1 시험은 멀쩡했어요.
  • 램 칩: Windows 메모리 진단 47분 동안 오류가 없었어요.
  • 바이오스 판: 최신 3202로 올려도 꺼졌어요.
  • CPU만, 그래픽 카드만, 램만 세게 쓰는 시험: 모두 안 꺼졌어요.

전압으로 안 고쳐지면

  1. A1 슬롯 안에 먼지나 휜 핀이 있는지 손전등으로 보고, 바람으로 불어 내요.
  2. CPU 쿨러 나사 네 개가 고르게, 너무 세지 않게 조여 있는지 봐요. 한쪽만 세면 한 채널만 불안정해질 수 있어요.
  3. 그래도 안 되면 메인보드 교체를 측정값과 리뷰로 비교해서 골라요.
  4. 그동안은 램 하나를 B1에만 꽂고 쓰면 안정적이에요(16GB, 속도는 조금 느려짐).
