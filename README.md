# PC 수리 기록 (게임 작업과 별도)

이 저장소는 사장님 Windows PC가 작업 중에 갑자기 꺼지는 문제를 고치기 위한 기록과 안내만 담아요. 코드는 없어요.
클라우드 세션은 PC가 꺼진 동안(바이오스 화면, 부품 교체 중) 휴대폰으로 사장님을 돕는 데 써요.

## PC 사양
- CPU: Intel i7-8700K (6코어 12스레드, 정격 동작, 오버클럭 없음)
- 메인보드: ASUS PRIME B360M-K, 바이오스 **3202** (2026-11-23에 2416에서 올림)
- 램: 삼성 DDR4-2666 16GB × 2 (M378A2K43EB1-CWE), 일련번호 끝 **78B**(17C2F78B), **C91**(17C30C91)
- 그래픽 카드: ASUS TUF RTX 3080 OC (PCIe x16 하나, 받침대 있음)
- 파워: SuperFlower LEADEX VII GOLD 1000W ATX3.1 (2026-11-22 새로 교체)
- 저장장치: 삼성 980 1TB NVMe
- OS: Windows 11 Home

## 증상
- 무거운 작업 중 아무 기록 없이 꺼지고 20~35초 뒤 저절로 다시 켜짐.
- Windows 기록: Kernel-Power 41, 버그체크 0, 전원 버튼 기록 없음, WHEA 오류 없음, 덤프 없음.
- 2025-12부터 100번 넘게 일어남.

## 재현 방법
블렌더 model_check 6개를 동시에 돌리는 시험(`repro_mc6.sh`, PC의 `C:\dev\jobs\crashlog\repro`). 고장 상태면 몇 초 만에 꺼짐.

원인이 아닌 것으로 확인: 파워(새것으로도 꺼짐), 그래픽 카드(꺼질 때 쉬는 중, x4에서도 B1 시험 멀쩡), 램 칩(Windows 메모리 진단 47분 오류 없음), 바이오스 판(3202도 꺼짐), CPU만·GPU만·램만 세게 쓰는 시험(모두 안 꺼짐).

## 지금 하는 일
- 바이오스 Ai Tweaker에서 **CPU System Agent Voltage(VCCSA)를 1.15V**로 올림(사장님 완료). **CPU VCCIO Voltage는 메뉴에 없음**(B360 보드라 흔함).
- (2026-11-23 클라우드 세션) VCCIO는 더 찾지 않음. 이 보드에서 메모리 컨트롤러에 가장 직접 영향을 주는 전압은 VCCSA라서, VCCSA 1.15V 시험만으로 전압 단계를 판정함. 1.15V는 8세대 CPU에 안전한 범위(보통 1.25V 이하 권장). 클라우드 세션에서는 ASUS 사이트(asus.com, dlcdnets.asus.com)가 네트워크에서 막혀서 설명서 원문을 확인하지 못함.
- 판정 기준: A1 시험에서 **안 꺼지면** VCCSA 1.15V 유지 → 그다음 78B+C91 둘 다(A1+B1) 시험. **또 꺼지면** VCCSA를 Auto로 되돌리고 다음 순서 1번(A1 슬롯 청소)으로.
- **결과(20:05~20:13): 78B 하나 · A1 · VCCSA 1.15V → 14판 모두 안 꺼짐**(전압 올리기 전엔 같은 조건에서 8초 만에 꺼짐). CPU 최대 110%, 남은 램 최저 2.3GB, PCIe x16.
- 다음: 램 두 개(A1=78B, B1=C91)를 다시 꽂고 VCCSA 1.15V 그대로 20판 시험. 버티면 본 작업을 다시 시작하고 지켜봄.
- **결과(20:19): 램 둘(A1=78B, B1=C91) · VCCSA 1.15V → 시작 약 7초 만에 꺼짐**(CPU 85%, GPU 쉬는 중, x16). 전압으로 A1 하나는 버텼지만 둘(듀얼 채널)은 아직 못 버팀.
- 다음 후보: VCCSA 1.20V로 한 단계 더(안전 범위 안, 1.25V 이하), DRAM Voltage 1.20→1.25V, 또는 다음 순서의 A1 청소·쿨러 나사 확인. 그동안 일하려면 램 하나를 B1에만.
- 사장님 결정(20:2x): **VCCSA 1.20V로 올림.** 램은 둘 다(A1=78B, B1=C91) 그대로. 바이오스: Delete → F7 → Ai Tweaker → CPU System Agent Voltage 1.20 → F10. 켜지면 PC 쪽 세션이 같은 시험 20판.
- **20:24 바이오스 사진(클라우드 세션 확인): CPU System Agent Voltage가 Auto로 풀려 있었음.** 램 32768MB = 둘 다 꽂힘. 언제 풀렸는지 모름 → **20:19 램 둘 시험이 정말 1.15V로 돌았는지 불확실**(램 바꿔 꽂을 때나 갑자기 꺼진 뒤 풀렸을 수 있음). 앞으로는 값 넣고 F10 저장 → 다시 바이오스 들어가 값이 남았는지 확인 → 시험. 꺼진 뒤에도 매번 확인. 같은 사진의 +12V 12.096 / +5V 5.000 / +3.3V 3.360, CPU 39°C는 정상.
- **20:27 바이오스 사진: 이 보드는 VCCSA 최대 1.15V**(화면 안내: Min 1.05 / Max 1.15 / Standard 1.05 / Increment 0.1). 1.20V는 입력해도 1.15로 돌아감 → **1.20V 시험 불가.** 같은 화면 아래에 PCH Core Voltage(Auto), DRAM REF Voltage Control 메뉴 있음(건드릴 필요 없음).
- 다음 제안: VCCSA 1.15V를 F10 저장 → 다시 들어가 남았는지 확인 → **램 둘 시험을 1.15V 확실한 상태로 다시**(20:19 결과는 전압 불확실). 그래도 꺼지면 DRAM Voltage 1.25V 한 번, 또는 A1 청소·쿨러 나사로.

## 다음 순서 (전압으로 안 고쳐지면)
1. A1 슬롯 먼지·휜 핀 확인, 바람으로 청소.
2. CPU 쿨러 나사 네 개가 고르게, 너무 세지 않게 조였는지 확인(한쪽만 세면 한 채널만 불안정해질 수 있음). 대각선 순서로 조금씩.
3. CPU를 빼서 소켓 핀(휜 핀) 확인 — 위험하니 사진 보고 함께 판단.
4. 그래도 안 되면 메인보드 교체: 측정값과 리뷰로 비교해서 고름(LGA1151 v2, 8세대 지원: B360/B365/H370/Z370/Z390).
- 그동안은 램 하나를 **B1**에만 꽂으면 안정적(16GB, 싱글 채널).
